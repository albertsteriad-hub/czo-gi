# ASH CONVOY — Czołgi Pustkowi

Projekt gry 3D w klimacie realistycznego post-apo / low-dieselpunk.

## Kierunek
- Ciężkie, masywne pojazdy gąsienicowe z wymiennymi modelami 3D **każdego** modułu.
- Fizyka uwzględniająca masę, moment bezwładności, przyczepność, opory gruntu i obciążenie silnika.
- Zróżnicowany teren: lasy, wsie, szosy, mokradła, ruiny i kompleksy przemysłowe.
- Załoga, wyposażenie, uszkodzenia i eksploracja.
- Stonowana estetyka; docelowe materiały PBR, realistyczne światło i audio przestrzenne.

## Status
**Repozytorium zainicjowane.** Znajdujące się tu pliki PlayCanvas to początkowy kod systemów, a **nie jeszcze kompletny projekt edytora ani przeniesiona gra 0.4**. Ostatnia wersja przeglądarkowa 0.4 jest odrębnym prototypem; import wymaga osobnego etapu.

## Struktura
- `playcanvas/` — skrypty ESM dla przyszłej sceny PlayCanvas.
- `docs/ROADMAP.md` — plan produkcji.
- `docs/PLAYCANVAS_SETUP.md` — powiązanie edytora z kodem.
